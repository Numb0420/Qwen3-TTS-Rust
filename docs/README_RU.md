## Текущая конфигурация

Сервис Qwen3-TTS на Rust для Windows. Сейчас используется **Qwen3-TTS-12Hz-1.7B-Base, Q5_K_M, один движок**. Talker/Predictor работают через llama.cpp Vulkan, вокодер — ONNX Runtime на CPU. Проверено на **AMD Radeon 8060S**. Здесь приведены только измерения проекта; CUDA, Metal и другие машины не тестировались. Обновлено: 2026-10-08.

## Реализованные функции

- WebUI: полное аудио, WebSocket-поток, остановка, время первого звука и этапов.
- Загрузка WAV с точной расшифровкой, полный ICL-голос, загрузка после перезапуска.
- Отдельная обработка скорости/громкости (0–100), пропускается при 50.
- `<phoneme py="lù">六</phoneme>` заменяется на пиньинь с пробелом перед инференсом; это не встроенный SSML.
- Windows-лаунчер в трее, IP/порт и CPU/Vulkan в конфигурации, скрипты упаковки.
- Голоса: 39 (по умолчанию), xiaolu, xiaoyan. Файлы исключены из Git; Base не использует ID CustomVoice Serena/Vivian.

## Время первого пакета

**Windows / Radeon 8060S / Base 1.7B Q5 / Vulkan + CPU-вокодер**. Китайские новости, пустая инструкция; Temperature 0.7, Top-K 50, Top-P 1, seed 43, скорость/громкость 50. Четыре полных запроса после одного завершённого. От отправки в подключённый WebSocket до первого целевого PCM, а не до звука в браузере или завершения синтеза.

| Запуск / голос | Среднее | Диапазон |
| --- | ---: | ---: |
| Обычный локальный запуск / 39 | 322.47 ms | 313.31–333.28 ms |
| Портативный запуск из трея / 39 | 312.46 ms | 310.76–314.31 ms |

```text
他也提到，去年河北十个市，县，获评第七届全国文明城市，数量是前六届的总和，全国双拥模范城，实现设区市全覆盖。人民群众的安全得到切实维护。
```

Другой тест в тот же день: 39 337.61 ms, xiaolu 319.95 ms, xiaoyan 328.89 ms (по три запроса, предыдущий текст). Разность разных тестов не доказывает выигрыш оптимизации. Все 20 полных PCM в сравнении пакетов совпали побайтно; это касается проверенных версий и входов.

Влияют текст, голос, очередь и нагрузка. Пользователь сообщил 411 ms до пакета и 431 ms до звука; API-тест не воспроизвёл результат, причина не установлена. Первый запрос после обычного локального перезапуска занял около 2.47 s и исключён. Автоматического прогрева синтезом нет. **Гарантия ≤300 ms для каждого запроса не доказана.** Оптимизации: фиксированные проекции, диапазон семплирования, ранняя отправка четырёх кадров, обновление только состояний для отброшенного эталонного аудио и сокращение расчёта волны во втором вызове. Новые голоса проходят калибровку при запуске. См. раздел 34 и сравнение пакетов.

## Запуск и настройки

Распаковать полный пакет, запустить `启动TTS.exe`. Меню трея открывает страницу, настройки, журналы или останавливает сервис. Пользователям не нужны инструменты сборки Rust/Python/Visual Studio; Vulkan требует драйвер. Для разработки и упаковки нужны инструменты сборки. После изменения перезапустить:

`server-config.json`

```json
{
  "inference_device": "vulkan",
  "host": "0.0.0.0",
  "port": 3000,
  "speakers": ["39", "xiaolu", "xiaoyan"],
  "open_browser": true
}
```

[http://127.0.0.1:3000/](http://127.0.0.1:3000/)

**Исходники не являются готовым портативным пакетом.** Модели, runtime, EXE и JSON голосов исключены. Некоторые преобразованные модели, оптимизированные ONNX и бэкенды пока не опубликованы для скачивания. Подготовить совместимые файлы и собранный проверенный каталог релиза, затем запустить:

```powershell
pwsh -NoProfile -File .\start-webui.ps1
```

## Свои голоса

Чистый WAV одного говорящего без музыки и точная расшифровка. Web принимает 1–30 s; преобразует в 24 kHz, сохраняя оригинал. Full сохраняет коды, текст и вектор, Xvec — только вектор, это не эквивалент полного ICL. После загрузки перезапустить; ручные JSON добавлять через `-BaseSpeakers`.

```powershell
.\create-speaker.ps1 -AudioPath .\reference.wav -Name my-voice -Mode Full -RefTextFile .\reference.txt
.\create-speaker.ps1 -AudioPath .\reference.wav -Name my-voice-xvec -Mode Xvec
pwsh -NoProfile -File .\start-webui.ps1 -BaseSpeakers my-voice
```

## API

HTTP/WebSocket используют общий порт (3000). `POST /api/tts`: JSON с WAV Base64; `GET /api/speakers`: голоса; `GET /health`: статус. Отправить этот JSON на `ws://127.0.0.1:3000/api/tts/stream`. Для совпадения с WebUI указать параметры явно; без Temperature сервер использует 0.

```json
{
  "text": "你好，今天天气很好。",
  "speaker": "39",
  "temperature": 0.7,
  "top_k": 50,
  "top_p": 1,
  "seed": 43,
  "instruction": "",
  "speed": 50,
  "volume": 50
}
```

Бинарные сообщения: моно PCM 24 kHz Float32 little-endian. `segment_done` завершает сегмент; текст `end` завершает ввод, затем приходит `done`. Для отмены закрыть WebSocket; `end` не отменяет, отдельного HTTP API остановки нет. После `done` доиграть полученное аудио. При Temperature 0 Talker выбирает максимум, его Top-K/Top-P не действуют. Predictor сохраняет отдельные настройки (0.9 / 50 / 1).
